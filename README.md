# Murat Bahadır KAYIHAN - Kişisel Portföy Sitesi

Bu repository, kişisel portföy websitemi içermektedir. Site, GitHub Pages üzerinde kayihan.tech adresinde yayınlanmaktadır.

## Özellikler

- Modern ve minimalist tasarım
- Responsive layout
- Dark tema
- Tailwind CSS ile stillendirilmiş
- GitHub Pages ile hosting

## Sayfalar

- Ana Sayfa (Hakkımda)
- Yetenekler
- Projeler
- Blog
- İletişim

## Teknolojiler

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- GitHub Pages
